# No Escape Docs

This repository contains public documentation, notes, designs and ideas about the video game, No Escape being written by Adalid Claure (github.com/zethon).

### Overview

No Escape is a horror/survival game that takes place on an island community. The player is the patriach of a family who lives on the island that is being invated. 

The object of the game is to lead the entire family to one of multiple escapes.

### Technicals

No Escape is being developed in Unity 6, using C#. The game is currently open source, and is primarily being developed on stream at https://www.youtube.com/@AddyGoesLive.
